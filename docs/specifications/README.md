# External specifications

The standards the S-124 and SECOM work is written against. None is kept here: the IMO circular and
the SECOM interface definitions, which this repository has no stated permission to redistribute;
the IHO's standards, whose copyright notice does not allow their redistribution; and the working
group's unpublished drafts.

| Document | Where |
|---|---|
| IMO MSC.1/Circ.1310/Rev.2, Joint IMO/IHO/WMO Manual on Maritime Safety Information (24 June 2024) | the IMO: https://www.imo.org (its circulars: https://docs.imo.org, with an IMO web account); the IHO publishes the manual as its publication S-53: https://iho.int/en/standards-and-specifications |
| SECOM (IEC 63173-2): the information service, PKI and service discovery interfaces, OpenAPI, version 2 | the IEC, whose working group TC 80 WG 17 the definitions name as their contact; the standard IEC 63173-2: https://webstore.iec.ch |
| IHO S-100, Universal Hydrographic Data Model, Edition 5.2.0 | the IHO: https://iho.int/en/s-100-universal-hydrographic-data-model |
| IHO S-124, Navigational Warnings Product Specification, Edition 2.0.0 | the IHO: https://iho.int/en/s-100-based-product-specifications |
| Service Design and Service Specifications for the Provision of Navigational Warnings to End-users (SECOM; v0.995 and v0.996, the working group's drafts of 16 June 2026) | not published; from the working group |

The IHO's standards in general: https://iho.int/en/standards-and-specifications.
